# Getting or updating the repository

The repository is already online at https://github.com/bodanmakerpro-max/Universal-Robotics-Control-Hub.

## Download for editing

Use **Code > Download ZIP**, extract it and open the root KiCad .kicad_pro file. Or use:

    git clone https://github.com/bodanmakerpro-max/Universal-Robotics-Control-Hub.git

## Upload later changes

After editing the schematic and PCB, commit the matching .kicad_pro, .kicad_sch and .kicad_pcb together. Do not commit a personal .kicad_prl lock/session file. Run KiCad ERC and DRC before publishing a claim that the board is electrically or manufacturably complete.

The old script for publishing to a **new blank GitHub repository** is obsolete for this already-existing repository and has been removed.

See [KICAD_EDITABLE_PROJECT](docs/KICAD_EDITABLE_PROJECT.md) for the exact current filename and opening instructions.

# Current STM32 dual-module carrier: R4

This folder contains the **original R4 PDF guide and PDF schematic** found in the project file archive. They are not a substitute for editable KiCad sources.

- `Elektronche_Carrier_Guide.pdf`: dated 19 Nov 2026, 3 pages, PCB render, pin map, power/protection notes, checks and test caveats.
- `Elektronche_Carrier_Schematic.pdf`: 1-page exported KiCad schematic of STM32 dual-module carrier.

The R4 guide itself references `Elektronche_Carrier_R4.kicad_sch`, a KiCad PCB and BOM files, but those **editable source files were not available** during this repository package creation. Add the originals here once recovered, without inventing replacement schematics. Do not fabricate from the PDF alone without a full review.

**Status:** DRC/ERC pass stated in the guide. Not assembled or tested. Verify all component and pin footprints before production.

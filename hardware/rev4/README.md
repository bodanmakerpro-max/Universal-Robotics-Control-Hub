# R4 design documentation (19 November 2026)

This folder preserves the **historical R4 PDF guide and schematic**.

- **Elektronche_Carrier_Guide.pdf**: routing illustration, power goals, pin map and reported checks.
- **Elektronche_Carrier_Schematic.pdf**: exported schematic.

**Update, 22 November 2026:** A newer complete **editable KiCad source set** was uploaded to the [repository root](../../README.md#download-and-open-the-editable-project). The root contains .kicad_pro, .kicad_sch and .kicad_pcb files. These PDF documents remain helpful design references but have **not** been independently cross-checked against the new uploaded board.

The R4 guide's earlier reported ERC/DRC results are not a validation of the latest root files. Review the [current validation status](../../docs/VALIDATION_STATUS.md).
